# zzwong/homebrew-tap

Homebrew casks for [zzwong](https://github.com/zzwong)'s tools.

```sh
brew install zzwong/tap/fourbysix
```

| Tool | Description |
|------|-------------|
| [fourbysix](https://github.com/zzwong/fourbysix) | Crop shipping and return-label PDFs onto 4x6 thermal labels |

Casks are published automatically by each tool's release workflow; don't
edit them by hand.
